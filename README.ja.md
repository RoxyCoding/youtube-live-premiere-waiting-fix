# YouTube Fix - ライブ再生の固まり修正

YouTubeのライブ配信やプレミア公開が、開始済みなのに待機画面のまま固まってしまう問題を修正するTampermonkeyユーザースクリプトです。

まず動画プレイヤーだけを再接続します。10秒以内に再生を確認できない場合は、ページ全体を再読み込みして再生を再試行します。この場合、チャットなどのページ状態も再読み込みされます。連続した再読み込みは60秒間抑止します。

## 対応する問題

- 予定開始時刻を過ぎても再生が始まらない
- 予定より早く配信が始まった場合に再生が始まらない
- 「あとX分で開始」「あとX秒で開始」のカウントダウンが更新されなくなる

## 動作要件

- ChromeやEdgeなどのChromium系ブラウザ
- Tampermonkey
- YouTube Data APIキーが必要です

有効なAPIキーが設定されていない場合、スクリプトはページを変更せず、動画プレイヤーも操作しません。

## インストール

[Tampermonkeyでインストール](https://raw.githubusercontent.com/RoxyCoding/youtube-live-premiere-waiting-fix/refs/heads/main/youtube-live-premiere-waiting-fix.user.js)

上のリンクをクリックし、Tampermonkeyの画面でインストールを確定してください。インストール後、YouTubeのライブ配信またはプレミア公開のページを開いてください。

## APIリクエストの制御

スクリプトはYouTube Data APIを最大30秒に1回だけ確認します。タブがバックグラウンドにある間はAPIポーリングを停止し、同じ動画をポーリングするのは表示中のタブ1つだけです。レート制限や一時的なサーバーエラーに対しては上限付きの指数バックオフを使用します。

再生の再試行はYouTube内部のプレイヤーリクエストを繰り返し発生させないよう、2秒に1回までに制限されています。

自動復旧のためのページ再読み込み後も、再生の再試行を引き継ぎます。ブラウザが音声付きの自動再生を拒否した場合は、ミュートで再試行します。

## 制限事項

Chromiumやオペレーティングシステムがタブを破棄したり、ブラウザプロセスを中断した場合、正確な監視間隔は保証できません。
